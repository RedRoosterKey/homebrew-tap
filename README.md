# Redroosterkey Tap

## How do I install these formulae?

`brew install redroosterkey/tap/<formula>`

Or `brew tap redroosterkey/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "redroosterkey/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
